refactor: Context-first effects + Attributes/Modifiers system overhaul

MAJOR REFACTORING SESSION: Core ability system architecture upgraded.
This commit consolidates 3 weeks of design iteration into a cohesive 
stat scaling + modifier composition system for instant and over-time effects.

== ARCHITECTURE CHANGES ==

1. Effects now receive AbilityContext at construction (not apply time)
   - DamageEffect/DOTEffect/ApplyEffectAction updated
   - Enables abilities to pass level, metadata, custom payloads to effects
   - Clean separation: CreateEffect reads context/config; ApplyTo just executes

2. Attributes + Modifiers system replaces legacy Resource model
   - AttributeDefinition (factory for Attribute runtime objects)
   - ConsumableAttributeDefinition (max + current amount tracking)
   - Attribute (base + runtime values, modifier composition)
   - AttributeModifier (scales by another attribute with three strategies)
   - ModifierSource enum (Caster/Target resolved at effect apply time)

3. Modifier composition via visitor pattern
   - Priority-ordered modifiers compose on Attribute
   - Three application strategies:
     * Base: scales from bonus attribute base value
     * Runtime: scales from bonus attribute runtime value
     * Current: scales from consumable attribute current amount (e.g., health)
   - Snapshot at effect creation; reapplyable via OverTimeEffectLifetimeManager

4. Over-time effects now support full modifier pipeline
   - OverTimeEffect.ApplyModifiers(target) extension point
   - DOTEffect implements modifier resolution mirroring DamageEffect
   - ClearModifiers() + re-add pattern prevents duplicate stacking on reapply
   - Snapshot damage-per-tick + dynamic mitigation hybrid model supported

5. Hybrid damage evaluat model validated
   - Damage scales from snapshot caster ability_power at apply time
   - Each TakeDamage call can apply live target armor/shields/vuln
   - Effect layer stays pure; target layer applies defensive reaction

- DamageEffectDefinition list of modifiers (designers author modifier SOs)

== DESIGN DECISIONS DOCUMENTED ==

1. String keys for attribute names (pragmatic for MVP)
   - Trades typo fragility for authoring simplicity
   - Validation layer recommended in hardening pass

2. Snapshot + dynamic hybrid model for effects
   - Effects snapshot source-side scalings (ability power, level)
   - Targets apply defensive logic on impact (armor, shields)
   - Prevents 100-zombie stacking bugs via instance-scoped resolution

3. Modifiers reapply safe by design
   - DOTEffect clears old modifiers before re-adding
   - Scales correctly when source/target stats change mid-effect

4. Event signaling added to Attribute changes
   - OnRuntimeValueChanged / OnBaseValueChanged hooks ready
   - Enables future UI/animation binding without plumbing everywhere
